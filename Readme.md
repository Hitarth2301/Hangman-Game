# Python Hangman Project

This is my project for the Python Essentials flipped course evaluation. It is a simple text-based Hangman game that works in the command line.

## How to run it
You don't need to install any extra packages. It just uses basic Python 3.

1. Clone this repo: `git clone https://github.com/yourusername/your-repo-name.git`
2. Open terminal or cmd in that folder.
3. Run the file by typing: `python Hangman_Game.py`

## How to play
The game gives you a hidden word and 6 lives. Type a letter and hit enter to guess. 
If the letter is in the word, it fills the blank. If it's wrong, your lives decrease by 1. Try to guess the full word before lives reach 0.
