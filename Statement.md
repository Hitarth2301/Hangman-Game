# Problem Statement

**Project:** Terminal Hangman Game

**The Problem:**
I needed to build a working Python program for my course evaluation that runs purely in the command line. The challenge was to combine different basic programming concepts like loops, conditionals, and array manipulation into one script that handles user input without crashing.

**The Solution:**
I solved this by making a Hangman game. It runs in a continuous `while` loop, takes user input directly from the terminal, checks if the input is valid, and updates the game board. It proves I can use Python basics to make an interactive command-line app without needing to rely on any outside libraries.
